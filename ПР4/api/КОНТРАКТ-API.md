# Контракт учебного API «Кинотеки»

Сервер — `server/mock-server.js` (Node.js, без внешних зависимостей).

```
node mock-server.js --port 8080 --origin http://localhost:5555
```

| Параметр   | По умолчанию              | Назначение                                        |
|------------|---------------------------|---------------------------------------------------|
| `--port`   | `8080`                    | порт сервера                                      |
| `--origin` | `http://localhost:5555`   | разрешённые источники CORS, через запятую         |
| `--seed`   | `seed.json` рядом с сервером | начальный набор данных                         |
| `--quiet`  | —                         | не печатать журнал запросов                       |

Данные живут в памяти. После перезапуска сервера возвращается начальный набор:
42 фильма, 14 режиссёров, 10 жанров, 12 киностудий, 14 зрителей.

Базовый адрес: `http://localhost:8080/api`. Все тела запросов и ответов — JSON в UTF-8.

## Служебные адреса и параметры

| Запрос                    | Ответ                                                  |
|---------------------------|--------------------------------------------------------|
| `GET /api/__health`       | `200 {"status":"ok","time":"…","counts":{…}}`          |
| `POST /api/__reset`       | вернуть начальный набор данных                         |
| `?__delay=1500` у любого запроса | ответ задерживается на 1500 мс (не больше 30 с) |
| `?__fail=500` у любого запроса   | ответ с этим кодом (400–599) и текстом ошибки   |

## Коллекции

`{c}` — одна из `movies`, `directors`, `genres`, `studios`, `viewers`.

| Метод и адрес                    | Назначение                                   | Успех |
|----------------------------------|----------------------------------------------|-------|
| `GET /api/{c}`                   | страница списка (поиск, фильтры, сортировка) | 200   |
| `GET /api/{c}/all`               | все записи для справочников                  | 200   |
| `GET /api/{c}/{id}`              | одна запись                                  | 200   |
| `POST /api/{c}`                  | создание                                     | 201   |
| `PUT /api/{c}/{id}`              | изменение                                    | 200   |
| `DELETE /api/{c}/{id}`           | в корзину (мягкое удаление)                  | 204   |
| `DELETE /api/{c}/{id}?hard=true` | удаление навсегда                            | 204   |
| `POST /api/{c}/{id}/restore`     | восстановление из корзины                    | 200   |
| `POST /api/{c}/bulk-delete`      | множественное удаление `{"ids":[…],"hard":false}` → `{"deleted":N}` | 200 |
| `POST /api/viewers/{id}/visit`   | отметить посещение по карте зрителя          | 200   |
| `GET /api/studio-directors`      | `{"<studioId>":[directorId,…]}` для каскада в форме фильма | 200 |

### Параметры списка

| Параметр         | Пример          | Описание                                         |
|------------------|-----------------|--------------------------------------------------|
| `search`         | `брат`          | поиск без учёта регистра                         |
| `sort`           | `year,desc`     | поле и направление; неизвестное поле — по умолчанию |
| `page`           | `2`             | номер страницы, с 1                              |
| `size`           | `10`            | размер страницы, от 1 до 100                     |
| `includeDeleted` | `true`          | показывать записи из корзины                     |

Фильтры сущностей:

| Коллекция   | Поиск по                          | Фильтры                                                 | Сортировка |
|-------------|-----------------------------------|---------------------------------------------------------|------------|
| `movies`    | названию, оригиналу, номеру ПУ    | `genreId`, `studioId`, `directorId`, `yearFrom`, `yearTo` | `title`, `year`, `duration`, `rating` |
| `directors` | фамилии, имени, стране            | `country`                                               | `lastName`, `firstName`, `birthYear`, `country` |
| `genres`    | названию, описанию                | `category`                                              | `name`, `category` |
| `studios`   | названию, стране                  | `country`                                               | `name`, `country`, `foundedYear` |
| `viewers`   | фамилии, почте, номеру карты      | `tariff`                                                | `lastName`, `firstName`, `email`, `visitsLeft` |

Ответ:

```json
{ "items": [ … ], "page": 2, "size": 10, "total": 42 }
```

## Представление фильма

На запись уходят идентификаторы связей:

```json
{
  "title": "Начало", "originalTitle": "Inception", "year": 2010, "duration": 148,
  "rating": 8.7, "licenseNumber": "121000001",
  "studioId": 1, "directorIds": [1], "genreIds": [2, 8, 3]
}
```

Приходят развёрнутые объекты:

```json
{
  "id": 1, "title": "Начало", "…": "…", "deletedAt": null,
  "studio":    { "id": 1, "name": "Warner Bros.", "country": "США" },
  "directors": [ { "id": 1, "firstName": "Кристофер", "lastName": "Нолан" } ],
  "genres":    [ { "id": 2, "name": "Фантастика" }, { "id": 8, "name": "Боевик" } ]
}
```

Зритель передаётся с вложенной картой (один к одному):

```json
{
  "lastName": "Иванов", "firstName": "Алексей", "email": "ivanov.a@mail.ru", "phone": "",
  "card": { "number": "KT-100037", "tariff": "Премиум", "visitsLeft": 24, "issuedAt": "15.01.2026" }
}
```

## Ошибки

Тело любой ошибки:

```json
{ "message": "Текст для пользователя", "errors": { "поле": "текст" } }
```

`errors` есть только у кода 422. Ключи совпадают с именами полей модели, у вложенной карты
зрителя — путь через точку: `card.number`, `card.tariff`, `card.visitsLeft`, `card.issuedAt`.

| Код | Когда                                                                             |
|-----|-----------------------------------------------------------------------------------|
| 400 | тело запроса — не JSON                                                            |
| 404 | нет записи или адреса                                                             |
| 405 | метод не поддерживается для адреса                                                |
| 409 | удаление студии, на которую ссылаются фильмы; удаление навсегда режиссёра или жанра со связанными фильмами; посещение по карте без остатка |
| 422 | данные не прошли проверку: формат, диапазоны, уникальность номера ПУ, почты, номера карты, названия жанра, существование связанных записей |
| 500 | внутренняя ошибка или `?__fail=500`                                               |

Пример 422:

```json
{
  "message": "Ошибка валидации",
  "errors": { "licenseNumber": "Фильм с таким номером удостоверения уже есть в каталоге" }
}
```

Пример 409:

```json
{
  "message": "Нельзя удалить киностудию: на неё ссылаются 9 фильмов (например, «Солярис»). Сначала укажите этим фильмам другую студию."
}
```

## CORS

Сервер отвечает заголовками `Access-Control-Allow-Origin` только для источников из `--origin`.
Предварительный запрос `OPTIONS` получает `204` с разрешёнными методами
`GET, POST, PUT, DELETE, OPTIONS` и заголовками `Content-Type, Authorization`.
Предварительный запрос с чужого источника получает `403` без заголовков CORS, и браузер не
отправляет основной запрос. Клиент на Dio передаёт заголовок `Content-Type: application/json`
даже у GET, поэтому предварительный запрос уходит перед каждым обращением. В журнале сервера
такие запросы помечаются `[CORS: источник … не разрешён]`.
